## AI workspace

Thư mục này là “bộ khung” để bạn video-code + bảo trì project theo vibe chuyên nghiệp:

- `docs/ai/skills/`: checklist kỹ năng + chuẩn coding/UX/QA trong repo
- `docs/ai/knowledge/`: kiến thức nền (architecture, data model, conventions)
- `docs/ai/agents/`: hướng dẫn vai trò agent + playbooks xử lý bug/feature

Mục tiêu: ai vào repo cũng hiểu **luồng dữ liệu**, **điểm chạm quan trọng**, và **cách thay đổi mà không làm vỡ UI**.
