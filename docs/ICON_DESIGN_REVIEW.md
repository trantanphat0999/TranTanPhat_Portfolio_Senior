The portfolio distinguishes product identity from the capability being described.

Product identities use local artwork: Postman, Apache JMeter, ZAP, akaAT Studio,
JavaScript, SQL Server, Jira, GitHub Actions, Windows Task Scheduler, ChatGPT,
Claude, Grok, n8n, Selenium, Docker, Chrome and social platforms. Asset provenance
is recorded in `image/tools/sources.json`. Google, Anthropic, Udemy, HUIT and
existing employer artwork remain their own brand assets.

Abstract concepts use original SVG geometry on a 24 × 24 grid, with 1.8 px
rounded strokes: API exchange, testing, manual testing, test documentation,
UI testing, performance, security, automation, CI/CD, AI-assisted QA, mentorship
and the site's navigation/editing controls. These symbols describe functions;
they are not fabricated product logos.

The shared renderer handles hero badges, skills, experience highlights, summary,
achievements, project technology tags, social links and admin controls. Legacy
icon classes remain in the stored portfolio and markup so existing forms, click
handlers and category color selectors continue to work. Newly opened admin
controls and icon changes are decorated through a batched DOM observer.

Brand artwork keeps its source colors, aspect ratio and neutral backdrop.
GitHub uses a transparent SVG mark; Facebook uses the current circular primary
logo from Meta's asset pack. JavaScript uses a custom circular yellow badge,
with the original JS letter paths centered and kept intact.
Multi-product labels such as ChatGPT / Claude / Grok show a compact logo group.
Decorative artwork is hidden from assistive technology; adjacent text and the
existing accessible button/link labels provide the meaning. The site does not
require a remote icon font for its current icons.
